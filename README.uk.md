# RUINWOOD (Руїноліс)

**Мультиплеєрна roguelike-RPG, у яку грають через звичайний `telnet`.** Написана на [Bun](https://bun.sh) і TypeScript, без залежностей під час виконання.

🇬🇧 [English version](README.md) — основна документація.

```
╦═╗╦ ╦╦╔╗╔╦ ╦╔═╗╔═╗╔╦╗
╠╦╝║ ║║║║║║║║║ ║║ ║ ║║
╩╚═╚═╝╩╝╚╝╚╩╝╚═╝╚═╝═╩╝
```

Сервер генерує випадковий острів: море, пляжі, луки, ліси, пагорби, гори й руїни зі скринями. Гравці підключаються звичайним telnet-клієнтом, бачать одне одного на карті й разом б'ють монстрів. Що далі від табору, то сильніші моби.

## Можливості

- **Мультиплеєр у реальному часі** в будь-якому терміналі, 10 тіків на секунду.
- **Процедурний світ** із фрактального шуму: той самий seed дає той самий острів.
- **Бій і лут**: шість видів монстрів, меч, бомби, зілля, сувої повернення, скрині й контейнери серця.
- **Дві мови**: англійська й українська. Кожен гравець обирає свою і може перемкнути її будь-коли.
- **Меню налаштувань**: мова, звук, ніки над гравцями, бічна панель, камера. Усе зберігається разом із героєм.
- **Ощадний рендер**: кадри порівнюються порядково, надсилаються лише змінені рядки. Повільний клієнт пропускає кадри, а не накопичує чергу.
- **Обидві розкладки**: WASD та інші клавіші працюють і на українській розкладці (ЦФІВ, У, Е, Р, Щ).

## Швидкий старт

```bash
bun install
bun start            # або `bun dev` — перезапуск при зміні коду
```

Підключення з іншого терміналу (на macOS: `brew install telnet`):

```bash
telnet localhost
```

> На Linux порти нижче 1024 потребують прав: один раз виконай `sudo setcap 'cap_net_bind_service=+ep' "$(which bun)"` або візьми інший порт: `PORT=2323 bun start` (тоді `telnet localhost 2323`).

Введи ім'я і грай: прогрес зберігається за ним. На титульному екрані **Tab** перемикає мову.

## Налаштування сервера

Сервер налаштовується змінними середовища:

| Змінна           | За замовчуванням        | Що робить                                         |
|------------------|-------------------------|---------------------------------------------------|
| `PORT`           | `23`                    | Порт сервера (стандартний порт telnet)            |
| `HOST`           | `0.0.0.0`               | Інтерфейс                                         |
| `SEED`           | з `data/world.json`     | Зерно світу (той самий seed → той самий світ)     |
| `DATA_DIR`       | `data`                  | Де зберігати світ і прогрес гравців               |
| `MAX_PLAYERS`    | `32`                    | Ліміт одночасних підключень                       |
| `DEFAULT_LOCALE` | `en`                    | Мова титульного екрана й нових гравців (`en` / `uk`) |

Щоб сервер за замовчуванням був українською:

```bash
DEFAULT_LOCALE=uk bun start
```

## Керування

| Клавіша             | Дія                                 |
|---------------------|-------------------------------------|
| WASD / стрілки      | Рух (у моба — удар)                 |
| Пробіл / 1          | Удар мечем у бік погляду            |
| 2 / E               | Випити зілля                        |
| 3                   | Кинути бомбу (вибух 5×5)            |
| 4                   | Сувій повернення в табір            |
| T                   | Чат (`/who`, `/quit`)               |
| O / Esc             | Налаштування                        |
| H                   | Довідка                             |
| Ctrl+C              | Вихід                               |

### Меню налаштувань

| Опція             | Значення                              |
|-------------------|---------------------------------------|
| Мова              | English, Українська                   |
| Звук              | увімк / вимк (сигнал терміналу)       |
| Ніки над гравцями | увімк / вимк                          |
| Бічна панель      | авто (від 100 колонок) / завжди / ніколи |
| Камера            | плавна (з мертвою зоною) / по центру  |

↑↓ або W/S — вибір, ←→ або Enter — змінити значення, Esc або O — закрити.

## Механіки

- **HP у серцях** (1 ♥ = 4 HP). Поза боєм здоров'я відновлюється повільно, біля вогнища `¤` швидко. Табір — безпечна зона.
- **Моби**: слиз `s`, кажан `v`, вовк `w`, гоблін `g`, скелет `S`, кам'яний голем `G`. Кожен живе у своєму біомі, а рівень залежить від відстані до табору.
- **Лут**: золото `$`, серця `♥`, зілля `!`, бомби `●`, сувої повернення `§`. Скрині `■` у руїнах дають золото й припаси, а іноді контейнер серця (+1 ♥ назавжди). Скриня наповнюється знову через 5 хв.
- **Смерть**: втрачаєш 25% золота, воно лишається на місці смерті, і його може підібрати будь-хто. Через 3 с відроджуєшся в таборі.
- **Прогрес** зберігається за ім'ям у `data/players.json`: кожні 30 с, при виході й при вимкненні сервера.

## Інтерфейс

- **Верхня панель**: серця й HP, рівень зі смугою досвіду, золото, сила, зона й небезпека, координати і здоров'я поточного ворога.
- **Хот-бар** під картою: слоти 1–4 з кількістю предметів. Слот підсвічується, коли його використовують.
- **Ніки** над іншими гравцями. Якщо в гравця мало HP, після ніка з'являється `!`.
- **Бічна панель** у широкому вікні: гравці онлайн зі стрілкою-напрямком і відстанню, журнал подій. У вужчому вікні журнал показується під хот-баром.

## Обмеження

- Паролів немає: хто вводить ім'я, той і грає цим героєм.
- `nc` теж працює, але без посимвольного введення: кожну команду треба підтверджувати Enter.
